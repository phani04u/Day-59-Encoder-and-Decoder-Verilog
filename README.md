## 🔹 Encoder
An encoder converts an active input signal into a binary-coded output.

**Example:** A 4-to-2 encoder converts four input lines into two output bits, assuming only one input is active at a time.

## 🔹 Decoder
A decoder converts binary input data into a corresponding output line.

**Example:** A 2-to-4 decoder uses two input bits to select one of four output lines.
